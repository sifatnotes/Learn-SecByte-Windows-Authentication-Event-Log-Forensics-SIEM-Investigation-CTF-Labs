## Categories

- **Authentication forensics:** Login activity, password changes, account lockouts, and authentication records.
- **Windows event analysis:** Event logs, event identifiers, and individual log entries.
- **Security monitoring:** Reviewing records for suspicious or unusual activity.
- **SIEM investigations:** Organizing evidence and prioritizing investigation leads.
- **Incident response:** Building a structured approach to investigating security events.

## Recommended Learning Path

1. Begin with **Login Lens** and **Login Trail**.
2. Continue with **Windows Auth Sleuth** and **Password Change Forensics Lab**.
3. Explore **Lockout Trail** to investigate account lockout activity.
4. Practice log analysis with **Event Log Hunt** and **Log Line Hunt**.
5. Progress to **Windows Event ID Hunt**, **Eventlog Forensics Forge**, and **Windows Event Logs Unlocked**.
6. Finish with **Windows Investigation Lab** and **SIEM Hunt: The Final Triage**.

Use each original lab's instructions and prerequisites to determine the most suitable order.

## How to Use the Labs

1. Choose a lab and open its Learn SecByte page.
2. Review the objectives and authorized exercise environment.
3. Follow the exercise instructions and inspect the available evidence.
4. Record relevant events, timestamps, findings, and conclusions.
5. Revisit unfamiliar concepts and practice interpreting logs accurately.

A failed login or account lockout is not automatically evidence of an attack. Correlate relevant events and context before drawing conclusions.
